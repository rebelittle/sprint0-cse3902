# Required tile sheet

Download **Tiny Blocks 1.1** from
[dani maccari's asset page](https://dani-maccari.itch.io/tiny-blocks-isometric-pixel-assets)
and place `tinyBlocks_NOiL.png` in this folder before building.

The sheet is omitted from the public repository because the creator permits
personal game use but prohibits redistributing the pack as assets. Commercial
projects require the creator's paid commercial license. Consult the linked
page for the full terms. The game's checkerboard uses the plain light and
plain dark gray blocks; the original sheet is unchanged.
