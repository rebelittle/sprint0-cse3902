# Sprint 0: Isometric Movement Demo

**Program made by Reagan Little.** A MonoGame DesktopGL demo with an orange,
eight-direction animated character on a gray isometric checkerboard. The camera
follows the player at 2x zoom. Keyboard and point-and-click controls move the same
character, and a blue animated circle follows the mouse.

## Controls

| Input | Action |
| --- | --- |
| WASD or arrow keys | Walk in eight directions by combining keys. |
| Left Shift + movement | Run at twice walking speed. Shift alone does nothing. |
| Left mouse click | Move to the clicked floor position at running speed. |
| Tab | Open or close the credits page. |
| Escape | Quit from the world screen. |

The pointer cycles through six frames every second. A new click replaces the
destination; keyboard movement cancels it. Clicks outside the floor are limited
to the floor boundary. Movement follows a straight line because there are no
obstacles. Diagonal keyboard movement has the same speed as movement along one
screen axis.

Opening credits cancels movement and pauses character and pointer animation.
Only Tab controls the game while credits are open. Losing window focus also
stops movement. This final Sprint 0 version does not include jumping.

## Build and run

### When cloning the public repository

The Tiny Blocks tile sheet is excluded from Git because the creator's terms
prohibit redistributing the pack as assets. Download **Tiny Blocks 1.1** from
[dani maccari's page](https://dani-maccari.itch.io/tiny-blocks-isometric-pixel-assets)
and place `tinyBlocks_NOiL.png` in `Assets/TiynBlocks_1.1/` before building.
The private course submission ZIP includes this required build input.

The architecture walkthrough is in [Sprint0_Architecture_Guide.md](Sprint0_Architecture_Guide.md).

### Visual Studio or terminal

This is a source submission; generated executables and build caches are excluded.
Use Windows with a Visual Studio installation that supports .NET 9 and `.slnx`
solutions, the .NET 9 SDK/runtime, and the standard Windows Arial font. The
project uses MonoGame 3.8.5.1. The first restore needs access to NuGet unless the
required packages are already cached.

1. Extract the ZIP before opening the project.
2. Open `sprint0_new.slnx` in Visual Studio.
3. Set `sprint0_new` as the startup project (the `Builder` project is a build tool).
4. Build and press F5 to run.

From a terminal in the extracted project folder:

```powershell
dotnet restore sprint0_new.slnx
dotnet run --project sprint0_new.csproj
```

The build automatically runs the separate content-builder project to compile
the three required images and the credits font into XNB content. Keep the
`Assets`, `Builder`, and source folders together with the project files.

## Code organization

`Game1` assembles the objects and coordinates input, updates, the camera, and
drawing. Separate keyboard and mouse controller classes request actions through
`IPlayer`. `Player` owns movement and delegates character animation to `ISprite`.
`SpriteSheet` supplies frame rectangles for character and pointer animation.
`FloorMap`, `IsometricProjection`, and `CreditsScreen` handle the map, coordinate
conversion, and credits display. `IController` and `IMouseController` define the
input contracts.
